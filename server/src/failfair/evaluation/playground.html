매칭 검사실

내 상황을 바꾸며 선배 사례 순위와 선택 근거를 직접 확인하세요.

상황 추출 이후의 검색 알고리즘만 검사합니다. Gemini는 호출하지 않으며, 입력은 저장하지 않습니다. 점수는 성공 확률이 아닙니다. 실제 서비스 화면과 별도의 개발용 검사 도구입니다.

일반 예시는 전체 시연 사례를, ‘한계 검사’는 대조 사례 2개를 검색합니다. 입력을 바꿔도 이 사례 집합은 유지됩니다.
